# Analysis and Design of an Online Banking System

An academic Systems Analysis and Design project by Elmira Orooji. The project follows an online banking system from user and system requirements through workflow modeling and object-oriented design. The repository contains three reports, primarily in Persian.

## Project scope

The proposed system covers customer authentication, password recovery, fund transfers, transaction history, bill payments, mobile airtime and data purchases, loan applications, and Sayad cheque registration. The context model identifies dependencies on external services such as the Shetab interbank network, civil registration services, mobile operators, and utility providers.
